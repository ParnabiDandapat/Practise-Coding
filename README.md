# Practise-Coding

A structured collection of programming practice, problem-solving exercises, and Data Structures and Algorithms (DSA) implementations in **C, C++, Java, and Python**.

This repository documents my coding journey, strengthens my programming fundamentals, and serves as a centralized archive of practice programs and continuous learning.

## 🎯 Objectives

- Strengthen programming fundamentals and logical thinking.
- Improve problem-solving skills through hands-on coding.
- Understand Object-Oriented Programming (OOP).
- Learn and implement Data Structures and Algorithms.
- Write clean, readable, and efficient code.
- Track continuous learning across multiple programming languages.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ParnabiDandapat/Practise-Coding.git
```

Then open the project in your preferred IDE or code editor and navigate to the folder for the language you want to practice.

Make sure the appropriate compiler, interpreter, or JDK is installed before running a program.
